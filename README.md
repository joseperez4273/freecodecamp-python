# Aprendiendo Python con freeCodeCamp

Repositorio donde guardo mis ejercicios y prácticas del curso de Python de [freeCodeCamp](https://www.freecodecamp.org/espanol/).

## Objetivo
Aprender Python desde cero y registrar mi avance de forma constante.

## Temas que he practicado
- Cadenas y f-strings
- Condicionales (`if`, `elif`, `else`)
- Operadores booleanos
- Funciones y alcance de variables

## Estructura
Cada archivo `.py` corresponde a un ejercicio:

- `01_employee_card.py`
- `02_ticket_booking.py`
- `03_commute.py`
- `04_kitchen_stock.py`

## Progreso
Actualizo este repositorio con cada ejercicio nuevo.
